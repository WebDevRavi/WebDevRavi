## Selected Projects

### Vortex Glide
Tunnel Rush–style 3D arcade game in Three.js and WebGL. Obstacles come from a seeded generator that checks every pattern is reachable before it spawns.

[Play](https://vortex-glide.vercel.app) · [Code](https://github.com/WebDevRavi/VortexGlide)

### TypeRush
60-second typing game in React, TypeScript and Vite. It tracks WPM and accuracy, never repeats a word within a round, and makes its own keyboard sounds with the Web Audio API.

[Play](https://typerush-ten.vercel.app) · [Code](https://github.com/WebDevRavi/Type_Dash)

### MathDash
Two-choice mental arithmetic game in React, TypeScript and Vite, with four difficulty levels, streaks, and a time bonus for fast answers.

[Play](https://mathdashgame.vercel.app) · [Code](https://github.com/WebDevRavi/Math_Dash)

### Find the Number
Number search game in plain HTML, CSS and JavaScript. Find 1–20, 1–50 or 1–100 in order, with Web Audio sound and light and dark themes.

[Play](https://find-number-xi.vercel.app) · [Code](https://github.com/WebDevRavi/FInd_Number)

### Color Trap
Browser game built with TypeScript and Vite.

[Play](https://colortrap.vercel.app) · [Code](https://github.com/WebDevRavi/Color_Trap)
